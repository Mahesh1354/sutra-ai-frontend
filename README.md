## 🚀 Overview

**Sutra AI** is a modern AI-powered chat interface built using **React + Tailwind + Vite**, designed for fast, real-time conversations with a clean and minimal UI.

It focuses on **performance, usability, and scalable frontend architecture**, making it suitable for production-level AI applications.

---

## ✨ Key Features

- 🤖 **Real-time AI Chat** (Streaming responses)
- 🎨 **Modern UI/UX** (Inspired by ChatGPT / Claude)
- 🌓 **Dark Mode Support**
- 📱 **Fully Responsive Design**
- 🔐 **JWT Authentication**
- 💬 **Conversation Management** (Create, Edit, Delete, Pin)
- 🔍 **Search Conversations**
- 📤 **Export Chat (Markdown / JSON)**
- ⚡ **High Performance (Vite + React 19)**

## ⚙️ Setup & Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Mahesh1354/sutra-ai-frontend.git
cd sutra-ai-frontend
````

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Setup Environment Variables

Create `.env.development` file:

```env
VITE_API_URL=http://localhost:8080/api
```

### 4️⃣ Run Application

```bash
npm run dev
```

👉 App runs at: **[http://localhost:5173](http://localhost:5173)**
